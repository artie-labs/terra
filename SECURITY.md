# Security

Never expose this database to the internet with the default passwords. `docker-compose.yml` and `pg/init/03_artie.sql` ship with placeholder passwords (`change-me-admin-password`, `change-me-to-a-long-random-string`) so the demo runs offline; change both before opening port 5432 to anything, and set `TERRA_ADMIN_PASSWORD` and `TERRA_ARTIE_PASSWORD` in the environment so the subscriber keeps working. If Artie must reach the source over the internet, run it on a host whose firewall allows inbound 5432 only from Artie's published egress IP ranges, which are listed on https://artie.com/docs/connection-options (recorded with the date read in `docs/sources.md`, key `artie-connection-options`); on AWS that is a security group rule per CIDR, on a bare VM a `ufw allow from <cidr> to any port 5432` per CIDR, and nothing from `0.0.0.0/0`. The `artie` role has only CONNECT, SELECT and REPLICATION, so a leaked password reads data but cannot change it; the `postgres` superuser password must stay off the wire. To report a problem with this repository, open a GitHub issue; do not include credentials in it.
